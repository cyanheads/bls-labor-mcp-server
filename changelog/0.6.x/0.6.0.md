# 0.6.0 — 2026-10-18

## Added

- **`bls_search_series` coverage** returns independently optional `startYear`, `endYear`, and `endPeriod` on both response surfaces, including EC's shifted coverage layout; coverage describes the catalog snapshot, not continuous observations. ([#90](https://github.com/cyanheads/bls-labor-mcp-server/issues/90))

## Changed

- **DataCanvas queries** now reject `current_setting`, `current_schema`, `current_schemas`, `in_search_path`, `query_table`, and `query()` with concatenated/cast SQL or nesting deeper than four levels.
- **Cold catalog harvests** omit a survey when any declared decoding table fails, even when upstream titles exist; with no usable survey, search reports `catalog_unavailable`. ([#94](https://github.com/cyanheads/bls-labor-mcp-server/issues/94))

## Fixed

- **Catalog refreshes** preserve each failed survey's complete prior rows and retry incomplete harvests on the next hourly check or boot. ([#94](https://github.com/cyanheads/bls-labor-mcp-server/issues/94))
- **Geographic search** prefers decoded places named in natural-language queries before candidate admission and final ranking, while keeping other matches eligible and exact SeriesIDs first. ([#98](https://github.com/cyanheads/bls-labor-mcp-server/issues/98))

## Security

- **Catalog search** bounds short-prefix expansion consistently in FTS candidate selection and rescoring, with linear token and geographic scans; longer stems retain prefix matching. ([#95](https://github.com/cyanheads/bls-labor-mcp-server/issues/95))
