# 0.7.1 — 2026-11-01

## Added

- **`bls_search_series` under `survey: "OE"`** composes OEWS SeriesIDs from the small OE code tables when OE rows are not indexed, at most 50 per search. Each row carries `composed: true` and is unconfirmed until `bls_get_series` returns data for it; `bls_get_series` and `bls_get_latest` name the state or national row to request when BLS reports a composed ID nonexistent. ([#119](https://github.com/cyanheads/bls-labor-mcp-server/issues/119))
- **Catalog surveys** SM, LE, EI, SU, IP, BD, LU, and EE are indexed and searchable. They stay out of the observation mirror, so their observations come from the live API. ([#120](https://github.com/cyanheads/bls-labor-mcp-server/issues/120))
- **`bls_list_surveys`** rows carry `searchCoverage` (`indexed`, `composed`, or `none`) and, when indexed, `seriesIndexed`; both are omitted while the catalog is still loading. ([#121](https://github.com/cyanheads/bls-labor-mcp-server/issues/121))
- **`catalog_loading` error reason** (ServiceUnavailable, retryable) for a `bls_search_series` call while a harvest builds an index with no series. `catalog_unavailable` now means no series and no harvest running, and its recovery names the hourly retry. ([#112](https://github.com/cyanheads/bls-labor-mcp-server/issues/112))
- **Observation mirror footnote tables**: each sync stores every survey's `{abbr}.footnote` table (schema v4, `bls_footnotes`). ([#118](https://github.com/cyanheads/bls-labor-mcp-server/issues/118))

## Changed

- **Catalog refresh** is per survey: each hourly check harvests only surveys past `BLS_CATALOG_CACHE_TTL_HOURS` and failed surveys whose retry came due (next check, then after 2, 4, 8 … checks, capped at the TTL). The index is `complete` only once every survey has succeeded. ([#104](https://github.com/cyanheads/bls-labor-mcp-server/issues/104))
- **`bls_search_series` `area`** takes a USPS or 2-digit state FIPS code, and 3-, 4-, 5-, or 7-digit CSA, CPI area, county or CBSA, and place codes, each matching the area it names; other values stay substring matches, with a notice for all-digit values of any other length. Under `survey: "OE"`, a USPS state code names the state. ([#110](https://github.com/cyanheads/bls-labor-mcp-server/issues/110), [#119](https://github.com/cyanheads/bls-labor-mcp-server/issues/119))
- **`bls_search_series` ranking**: exact SeriesIDs, then rows matching every query word (a place named in full leads them), then score; at equal score, current series precede ended ones, then national rows, then the JOLTS all-industry row. `core` beside a CPI or PPI alias selects the less-food-and-energy series. Function words (`of`, `per`, …) score a quarter of a content word. ([#105](https://github.com/cyanheads/bls-labor-mcp-server/issues/105), [#122](https://github.com/cyanheads/bls-labor-mcp-server/issues/122))
- **Observation mirror sync** exits 2 when it completes with unread files or with surveys whose listing names no data files, and 0 otherwise. ([#117](https://github.com/cyanheads/bls-labor-mcp-server/issues/117))

## Fixed

- **Query words in place names** no longer outrank real matches (`price of eggs` → `APU0000708111`). ([#105](https://github.com/cyanheads/bls-labor-mcp-server/issues/105))
- **Numeric and postal `area` values** no longer match inside SeriesIDs or words (`48` and `TX` reach the Texas statewide row). ([#110](https://github.com/cyanheads/bls-labor-mcp-server/issues/110))
- **PPI headline** boost points at Final demand (`WPUFD4`) rather than core PPI under a finished-goods description. ([#125](https://github.com/cyanheads/bls-labor-mcp-server/issues/125))
- **`area` filter** no longer returns headline series that match no query word. ([#129](https://github.com/cyanheads/bls-labor-mcp-server/issues/129))
- **Mirror checkpoint** advances only after a run reads every listed index and data file; each unread file logs a warning on the child's stdout. ([#117](https://github.com/cyanheads/bls-labor-mcp-server/issues/117))
- **Mirror data files** come from each survey's directory listing, so PC (all 71 files), 10 CE files, and one each from WP and JT are now read. ([#124](https://github.com/cyanheads/bls-labor-mcp-server/issues/124))
- **Mirror-served rows** carry `periodName` and `code: text` footnotes like the live API. ([#118](https://github.com/cyanheads/bls-labor-mcp-server/issues/118))
- **Mirror-served series** carry `measure` where the survey's code table supplies it. ([#127](https://github.com/cyanheads/bls-labor-mcp-server/issues/127))
- **Measure table failures**: a survey with no indexed rows whose measure table fails to download indexes without `measure`; a survey with rows keeps them. ([#127](https://github.com/cyanheads/bls-labor-mcp-server/issues/127))

## Upgrade notes

- `CATALOG_INDEX_VERSION` is 5: persisted catalog indexes re-harvest from LABSTAT once.
- The observations mirror store migrates to schema v4 and clears its checkpoint, so the next refresh re-reads every listed data file once.
