# 0.7.0 — 2026-10-31

## Added

- **BLS labor guide resource** covers SeriesID resolution, compatible comparisons, missing observations, annual summaries, and DataCanvas analysis; ships through npm, Docker, plugins, and the Claude Desktop bundle.

## Changed

- **DataCanvas** now rejects unqualified `current_schema` column references, including CTE projections; qualify the column with its table or alias.
- **DataCanvas defaults** to DuckDB for local and Docker starts; `CANVAS_PROVIDER_TYPE=none` disables it. The Claude Desktop bundle runs inline-only without DuckDB.
- **Request ceilings** clamp search and SQL limits with requested/applied notices; history processes 25 keyless or 50 keyed unique IDs, latest processes 50, and both return the exact ordered `unprocessedSeriesIds` remainder. ([#114](https://github.com/cyanheads/bls-labor-mcp-server/issues/114))

## Fixed

- **Applied request metadata** preserves BLS reduction advisories, reports reduced year bounds, and marks calculations applied only when every data-bearing series supplies calculation values. ([#106](https://github.com/cyanheads/bls-labor-mcp-server/issues/106))
- **Upstream failures** classify HTTP status before parsing, retry transient failures, expose typed recovery, and retain partial observations without blaming SeriesIDs for outages. ([#107](https://github.com/cyanheads/bls-labor-mcp-server/issues/107))
- **Live request deadlines** share a 45-second budget across headers, body reads, retry backoff, and catalog-free reissue; caller cancellation propagates. ([#108](https://github.com/cyanheads/bls-labor-mcp-server/issues/108))
- **Measurement metadata** uses decoded catalog titles and preserves optional BLS `measure` values in history, latest, and spilled dataframes. ([#109](https://github.com/cyanheads/bls-labor-mcp-server/issues/109))
- **SeriesIDs** are trimmed, uppercased, and deduplicated in first-occurrence order before retrieval and caps. ([#111](https://github.com/cyanheads/bls-labor-mcp-server/issues/111))
- **Canvas-disabled history** returns every fetched observation inline, including results above the spill threshold. ([#113](https://github.com/cyanheads/bls-labor-mcp-server/issues/113))
- **Registration clashes** recommend a fresh `register_as` name while preserving the existing table. ([#115](https://github.com/cyanheads/bls-labor-mcp-server/issues/115))
- **Tool contracts and documentation** describe fixed table expiry, BLS default windows and annual summaries, calculation support, rejection recovery, survey caching, and network annotations accurately. ([#116](https://github.com/cyanheads/bls-labor-mcp-server/issues/116))
- **Text rendering and bundle delivery** preserve literal upstream text and executable SDK skill modules; bundle cleanup removes development files and retains portable SQLite prebuilts.
