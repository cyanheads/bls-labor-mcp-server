# 0.5.4 — 2026-09-23

**Upgrade:** `CATALOG_INDEX_VERSION` is now `2`, so an index persisted by an earlier release re-harvests once on its first boot after upgrade. Searches keep running against the existing index while that harvest updates it in place, and a harvest that fetches nothing leaves it untouched and retries on the next boot.

## Added

- **`bls_search_series` `offset`** — optional integer ≥ 0 (default 0) that pages the ranked, filtered list; the response adds `offsetApplied` and, while `truncated` is true, `nextOffset`, with a `Pass offset: N for the next page.` notice. Paging reaches as deep as the candidate pool (1,000 FTS rows plus the headline and exact-ID rows); an offset past the end and the last page of a capped list each get their own notice. ([#62](https://github.com/cyanheads/bls-labor-mcp-server/issues/62))
- **Not-indexed survey notice** — a `survey` with no rows in the offline index now gets `Survey EN has no series in the offline catalog index (indexed: …)`, pointing to `bls_list_surveys` and `bls_get_series`; `OE` also names `BLS_CATALOG_INCLUDE_OES=true` while the opt-in is off. The indexed list is read from the index (`indexedSurveys`) once per load and after each harvest. ([#64](https://github.com/cyanheads/bls-labor-mcp-server/issues/64))

## Changed

- **`bls_search_series` descriptions** — the tool and `survey` descriptions derive their code list from `SURVEY_ABBRS` and mark `OE` as opt-in; `bls_list_surveys` and the server instructions note that search covers only the offline index, with other surveys fetched by SeriesID. ([#64](https://github.com/cyanheads/bls-labor-mcp-server/issues/64))
- **National rows first at equal score** — without `area`, a national row (no decoded area, `U.S. city average`, `Total US`, or OEWS `National`) outranks a state or metro row that ties it. Area-filtered order is unchanged.
- **Empty-page text** — `format()` renders `No series returned.` for an empty page; the notice carries the reason.
- **Catalog survey names** — JT is `JOLTS`, PR `Major Sector Productivity and Costs`, EC `ECI (SIC basis, ended 2005)`, and MP `Major Sector Total Factor Productivity`. ([#63](https://github.com/cyanheads/bls-labor-mcp-server/issues/63))

## Fixed

- **`bls_search_series` `area`** — the filter now runs in the SQL candidate query, before the 1,000-row cap, as an escaped case-insensitive `LIKE` on `area_name`, `title`, or `series_id` (`%`, `_`, `\` match literally), so broad queries no longer come back empty or partial; `totalCount` and `capped` describe the filtered pool. ([#69](https://github.com/cyanheads/bls-labor-mcp-server/issues/69))
- **`survey`/`area` normalization** — both filters are trimmed, a blank value counts as omitted (no filter, no `surveyFilter`/`areaFilter` echo, no remove-the-filter notice), and `survey` is uppercased, so `" cu "` applies and echoes `CU`. ([#70](https://github.com/cyanheads/bls-labor-mcp-server/issues/70))
- **JT, PR, and EC titles** — these surveys ship no `series_title`; their titles are now synthesized from an ordered dimension list (`JOLTS - Quits - Total nonfarm - Total US - All size classes - Rate`), so rows no longer share one title, and JT's `state_code` decodes as the area instead of the constant `All areas`. ([#63](https://github.com/cyanheads/bls-labor-mcp-server/issues/63))
- **Code-table decoding** — tables are parsed by header (declared `_code` key columns, first `_text`/`_name` label) instead of by position, and each survey declares its `area`/`item` dimensions: LA now decodes its area, PC and WP their product/item, CE its industry, and MP its sector. Only the tables a declared dimension names are fetched, so the ones that 404 are no longer requested; a missing or malformed table is reported on stderr. ([#83](https://github.com/cyanheads/bls-labor-mcp-server/issues/83))
- **`bls_list_surveys` categories** — `CATEGORY_MAP` now assigns every one of the 70 surveys to at least one category, following the BLS subject areas (CW and SU under `prices`, EN under `employment` and `wages`, IN under four); the `category` description notes that a survey can appear under several. ([#65](https://github.com/cyanheads/bls-labor-mcp-server/issues/65))
