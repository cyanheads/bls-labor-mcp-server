# 0.5.2 — 2026-09-19

## Changed

- **Tool error text** — an error whose data carries a `reason` or a boolean `retryable` now closes with `(reason <reason> · not retryable)` in `content[]`, and a cancelled call classifies as `RequestCancelled` (-32011) instead of a generic internal error.
- **Argument validation** — an invalid tool call now returns `InvalidParams` with `data.reason: "invalid_arguments"` and a schema-derived recovery hint, in place of a generic validation message.
- **Session posture** — the server declares `sessionMode: 'stateless'` in `src/`, and the `initialize` server card advertises the resolved mode.
- **Plugin install** — the Claude and Codex plugin manifests prompt for `BLS_API_KEY` through user config/env forwarding, instead of shipping an empty key that silently capped the daily quota at 25 requests.

## Fixed

- **`bls_dataframe_query`** — Markdown table cells escape backslashes before pipes, so a value like `x\|y` survives rendering instead of losing its backslash. ([#75](https://github.com/cyanheads/bls-labor-mcp-server/issues/75))
- **Graceful shutdown** — `createApp({ teardown })` closes the catalog and observations-mirror SQLite handles, which previously stayed open past process exit.
- **BLS upstream 500 responses retry** instead of failing on the first attempt, matching the 502/503/504 handling already in place.
