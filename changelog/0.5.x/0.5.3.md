# 0.5.3 — 2026-09-22

## Fixed

- **Observations mirror ingester** — the BLS `-` missing-value sentinel is now stored instead of discarded; a schema v2 migration clears the mirror's sync checkpoint on first open so an existing mirror backfills the rows on its next refresh. ([#58](https://github.com/cyanheads/bls-labor-mcp-server/issues/58))
- **Observations sync subprocess** — the child entry now initializes the mirror service before reading it, so both `--init` and the scheduled refresh run instead of exiting on an uncaught error. ([#72](https://github.com/cyanheads/bls-labor-mcp-server/issues/72))
- **Mirror-routed `bls_get_series`** — `series[]` now returns in request order, and a SeriesID no source resolved stays visible as a zero-observation entry instead of being dropped. ([#73](https://github.com/cyanheads/bls-labor-mcp-server/issues/73))
- **LABSTAT file discovery** — the ingester now reads each survey's `{abbr}.txt` index instead of an `{abbr}.readme` no survey serves; a survey whose index yields no files is logged and skipped instead of falling through to a guessed filename. ([#78](https://github.com/cyanheads/bls-labor-mcp-server/issues/78))
- **`bls_get_series` all-empty batches** — the failure reason is now composed from every BLS advisory instead of the first invalid SeriesID, and the message lists every advisory per SeriesID rather than only the last one seen. ([#59](https://github.com/cyanheads/bls-labor-mcp-server/issues/59))
- **`start_year`/`end_year`** — a one-sided bound is now resolved in the handler before the request: `start_year` alone caps `end_year` at `start_year + 19`, and `end_year` alone is rejected before spending a query. ([#76](https://github.com/cyanheads/bls-labor-mcp-server/issues/76))
- **Spill failures** — `canvas_unavailable` and `canvas_registration_failed` now name the year window actually applied, including one the handler resolved on the caller's behalf. ([#79](https://github.com/cyanheads/bls-labor-mcp-server/issues/79))

## Dependencies
