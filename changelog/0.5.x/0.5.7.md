# 0.5.7 — 2026-09-26

## Changed

- **Argument validation** inherits mcp-ts-core 0.13.9 integer-to-string repair and field-specific recovery hints; a fractional search limit explicitly asks for an integer.
- **Canvas SQL errors** inherit mcp-ts-core 0.13.8 classifications: unknown functions return `invalid_sql`, missing tables return `missing_table`, and write statements return `non_select_statement`.
- **Canvas scratch storage** inherits mcp-ts-core 0.13.9 private temporary directories (`0700` on POSIX), separate spill directories per canvas, and shutdown cleanup; `CANVAS_TEMP_PATH` names their parent directory.
- **Output-contract failures** inherit mcp-ts-core 0.13.8 `-32603` responses without error `data`; in-memory state inherits 0.13.7 JSON round-tripping.
- **HTTP protocol handling** inherits MCP SDK 2.1.0 through mcp-ts-core 0.13.9: a 2026-07-28 request missing `MCP-Protocol-Version` returns HTTP 400 / `-32020`; request headers must agree with the envelope.
- **Telemetry configuration** documents the 0.13.7 OTLP base endpoint for traces and metrics, plus 0.13.8 opt-in log export and failed-call payload logging. Failure payload redaction matches keys, not secrets inside free-form values.
- **Docker installs** retain the three-day package age guard and Socket scanner in production, resolve OpenTelemetry packages within framework peer ranges, include log-export peers, and remove the unused `MCP_FORCE_CONSOLE_LOGGING` setting.
- **Package contents** exclude `dist/*.mcpb` from npm and `docs/idea.md` and `logs/` from desktop bundles.
- **Documentation and tooling** condense the capability reference, align the `BLS_USER_AGENT` sample with its existing runtime default, document logging, resumability, and memory controls, and sync framework skills, definition-load checks, packaging validation, skill-version checks, and tag validation.
