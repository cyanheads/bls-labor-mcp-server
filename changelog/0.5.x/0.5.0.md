# 0.5.0 — 2026-08-30

## Changed

- **DataCanvas startup surface** — `bls_dataframe_describe` and `bls_dataframe_query` register only with `CANVAS_PROVIDER_TYPE=duckdb`; `bls_dataframe_drop` additionally requires `BLS_DATAFRAME_DROP_ENABLED=true`, while disabled definitions remain visible to operators. ([#66](https://github.com/cyanheads/bls-labor-mcp-server/issues/66))
- **Spilled `bls_get_series` results** — `dataset.truncated` is removed; successful spills always register the complete fetched table, while registration failures remain typed errors. ([#54](https://github.com/cyanheads/bls-labor-mcp-server/issues/54))
- **DataCanvas workflow** — spill guidance now directs callers to inspect `column_schema` with `bls_dataframe_describe` before using the table in `bls_dataframe_query`. ([#68](https://github.com/cyanheads/bls-labor-mcp-server/issues/68))
- **`bls_dataframe_query` preview notices** — preview-limited `register_as` results name the already materialized dataframe instead of suggesting another registration. ([#57](https://github.com/cyanheads/bls-labor-mcp-server/issues/57))
- **`bls_dataframe_describe` output** — `truncated` and `max_rows` are removed because registered tables are complete.

## Dependencies

- `@biomejs/biome` `^2.5.9` → `^2.5.11`
- `@types/node` `^26.2.0` → `^26.4.0`
