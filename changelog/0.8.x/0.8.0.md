# 0.8.0 — 2026-11-14

## Changed

- **Breaking: `bls_dataframe_query` refuses SQL that names a DuckDB metadata view** (`duckdb_columns`, `duckdb_constraints`, `duckdb_databases`, `duckdb_indexes`, `duckdb_logs`, `duckdb_schemas`, `duckdb_tables`, `duckdb_types`, `duckdb_views`, `pragma_database_list`, `sqlite_schema`, `sqlite_temp_master`, `sqlite_temp_schema`, `pg_am`, `pg_attrdef`, `pg_attribute`, `pg_class`, `pg_collation`, `pg_constraint`, `pg_database`, `pg_depend`, `pg_description`, `pg_enum`, `pg_index`, `pg_indexes`, `pg_namespace`, `pg_prepared_statements`, `pg_proc`, `pg_sequence`, `pg_sequences`, `pg_settings`, `pg_tables`, `pg_tablespace`, `pg_type`, `pg_views`) in any case, quoted or not, outside string literals and comments. 0.7.1 answered when one appeared as a column alias (with or without `AS`, and in `ORDER BY`), a table or subquery alias, a CTE name, a quoted alias containing one (`"pg_tables total"`), a staged column, or a `register_as` table or aliased column. An alias `sqlite_master` or `information_schema` after a `'--'` string literal is refused too; 0.7.1 read the `--` inside the literal as a comment. `register_as` refuses a name that is one of those views, `sqlite_master`, `information_schema`, or `pg_catalog` with the new reason `register_as_system_catalog`, before anything is staged (`duckdb_columns` and `duckdb_views` already failed in 0.7.1).
- **`bls_search_series`** ranks a survey's aggregate above its equal-score breakdowns: JT, CM, CI, and BD totals, and an area's CPI All items (CU, CW, SU item `SA0`). Among rows matching every query word, national aggregates enter the candidate pool first, and every aggregate does under an explicit `area`. ([#128](https://github.com/cyanheads/bls-labor-mcp-server/issues/128), [#132](https://github.com/cyanheads/bls-labor-mcp-server/issues/132))
- **A cut or failed catalog `.series` body** deletes none of the survey's indexed rows, and a survey that already had rows keeps the rows of the body's complete lines (0.7.1 wrote none); a survey's first harvest still keeps nothing from one. ([#126](https://github.com/cyanheads/bls-labor-mcp-server/issues/126))
- **`bls_dataframe_query`** accepts constant-argument `range()` and `generate_series()`, and reports non-SELECT statements as `non_select_statement` and file-path reads as `sql_read_only`; both are still refused.
- **`missing_table` error** names the table as code without quotes, and its recovery names `bls_dataframe_describe`.
- **Observation sync child** exits 3 when another process holds the mirror's sync lease.
- **`engines.bun`** is `>=1.4.4`.

## Fixed

- **`BLS_CATALOG_INCLUDE_OES`** indexes OE under Node: each `.series` file streams into the index line by line instead of being read as one string, and its read gives headers 30 s and each stalled chunk 60 s, with no whole-body deadline. ([#126](https://github.com/cyanheads/bls-labor-mcp-server/issues/126))
- **`bls_search_series`** ranks rows matching more of the query's words, a concept alias included, ahead of an alias-only headline. ([#131](https://github.com/cyanheads/bls-labor-mcp-server/issues/131))
- **SeriesIDs and dataframe names** render as code spans in `content[]` (rows, headings, failure lines, notices, error messages), so one with underscores reads without backslashes, as does a `bls_dataframe_query` cell that escaping would alter. The `bls_search_series` notice no longer reads a caller's raw `survey` text as Markdown. ([#133](https://github.com/cyanheads/bls-labor-mcp-server/issues/133))
- **Concurrent first stagings** share one canvas instead of orphaning dataframes on separate canvases; describe, drop, and the TTL sweep never create one; a drop after the canvas is gone reports `dropped: false`; a cancelled staging fails as cancelled. ([#135](https://github.com/cyanheads/bls-labor-mcp-server/issues/135))
- **`register_as: duckdb_columns` or `duckdb_views`** no longer leaves behind a table that fails every later `register_as` on the canvas.
- **`bls_dataframe_describe` `column_schema.type`** reports SMALLINT, TINYINT, UTINYINT, and USMALLINT columns of a `register_as` table as INTEGER instead of VARCHAR.
- **`bls_get_latest` footer** no longer joins the last failure bullet.
- **Catalog timing tests** measure thread CPU time through one shared helper instead of reading the wall clock or sleeping. ([#130](https://github.com/cyanheads/bls-labor-mcp-server/issues/130))
